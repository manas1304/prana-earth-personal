# Prana Earth

Internal repository for the Prana Earth ecosystem — a two-platform climate intelligence and sustainability product.

- **Predict Platform** (`pranaearth.com`) — Climate risk assessment, dashboards, scenario analysis, ESG insights, and downloadable reports for physical assets.
- **Marketplace** (`marketplace.pranaearth.com`) — Curated sustainability and water resilience project discovery, with AI-powered insights, Concept Note access, and interest workflows.

Both platforms share a unified authentication system and subscription model (Predict-only, Marketplace-only, or bundled Earth access).
